# JSON Behavior Import for Unity Behavior

Author [Unity Behavior](https://docs.unity3d.com/Packages/com.unity.behavior@latest) graphs as plain JSON and transcribe them into native, fully-compiled `.asset` files — no visual editor required.

Built for AI-assisted workflows: JSON is easy for an LLM or coding agent to generate, review as a diff, and validate, unlike a node graph's positional layout. Existing Action/Condition nodes (yours and Unity's built-ins) run completely unmodified, with full native debugger support.

## Status

This package is under active development on the [`develop`](https://github.com/shirousa/unity-jsonbehavior/tree/develop) branch. Tagged releases will land on `main` once the first stable version ships.
